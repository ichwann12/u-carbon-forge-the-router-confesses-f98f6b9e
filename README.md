A single line, at most 200 characters, that a home Wi-Fi router would say to
excuse itself for dropping the connection at the exact moment a movie reaches
its climax.

## The line

> I dropped the Wi-Fi at the exact climax because even I could not handle the suspense. Blame the buffering, not me.

## Run

```sh
node main.ts
```

Reads `entry.txt` from the repo root and writes it to `output.txt` in the
directory given by `MAKEFUN_BOT_DIR` / `MAKEFUN_OUTPUT_DIR` (defaults to
`output/`). Node 22+, stdlib only, no network, no wall clock.
